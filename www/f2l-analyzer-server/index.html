集める解の長さ

プラス ＋0手

集める長さ：7〜7手。一般的な手順の手数を基準にして、そこから何手短い解・長い解まで集めるか指定するよ。最短より長い長さだけを指定すると、探索に時間がかかることがあるよ。

探索の上限

120万手まで

大きくすると打ち切りが減る代わりに待ち時間が伸びるよ。スマホが熱くなる前に止めたいときは小さめに。

メモ

  • 並び順は回しやすさ（簡易MCC）優先。MCCはリサーチの値を土台にした簡易版で、型ボーナスは試作値（有名な型 −0.5、トリガー −0.3）。
  • 型の一覧は Sune / Anti-Sune / Sexy / Anti-Sexy / Sledgehammer / Hedgeslammer / トリガー系（左右バージョン含む）。
  • セットアップ：クロス面とスロットを指定すると、クロスと保持スロットが自動で埋まり、それ以外は黒（未定）になる。対象ペアは「置く」ボタンで置いて、クリックで向きを変える。
  • 探索には候補を試す回数の上限があって、深いケースでは途中で打ち切られて候補が一部だけになることがある（赤字で出るよ）。上限は無制限まで上げられるし、探索は途中でも中断できる。
